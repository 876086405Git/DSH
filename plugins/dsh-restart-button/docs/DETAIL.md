# 重启按钮（Restart button）

在 DSH 桌面端侧边栏底部新增一个「重启」按钮，点击后确认、再自动重启整个桌面端。

## 功能

- **位置**：侧边栏最底部一排（跟设置齿轮同一排），排在会话管理器按钮右侧。
- **确认**：点击先弹确认框，说明「这个窗口里还在跑的任务会被中断」，可取消。
- **执行**：确认后整个桌面端退出并自动重新打开，不需要再手动双击图标。
- **反馈**：提交成功立刻显示「正在重启…」遮罩；失败弹出错误框，带上具体原因（HTTP 状态、schtasks 输出、日志尾部），并给「重试一次」。

## 为什么必须这样实现

桌面端的进程结构是：Electron 主进程 → Host 子进程（本插件所在）。杀掉主进程会连带杀掉发起重启的代码本身，所以「关掉再拉起来」不能在本进程里做。

做法：把重启动作写成一个临时 PowerShell 脚本，用 **Windows 计划任务**（`schtasks /Create` + `/Run`）执行。计划任务的父进程是 `svchost.exe`，与 DSH 没有父子关系，因此杀掉 DSH 不会把它一起带走，它能继续把应用拉起来。

脚本行为：等 3 秒（让回执写回浏览器）→ 结束 `DeepSeek Harness` 进程 → 等进程真正退干净（最多 60 秒）→ 用原路径重新启动。

## 前置条件与失败情形

| 情形 | 表现 |
|---|---|
| 非桌面端（`dsh web` / CLI） | 错误框：当前不是桌面端窗口，没有可重启的应用 |
| 非 Windows | 错误框：暂只支持 Windows 桌面端 |
| 找不到桌面端可执行文件 | 错误框：找不到桌面端可执行文件路径，附注入路径与 `execPath` |
| `schtasks /Create` 或 `/Run` 失败 | 错误框：附返回码与原始 stdout/stderr |
| 重启后没起来 | 应用不会再弹提示（已退出），用错误框里的日志路径查看 `restart.log` |

## 限制

- 只支持 Windows。macOS / Linux 的桌面端不提供该按钮的可执行路径。
- 如果没有权限创建计划任务（受管控的机器），`schtasks` 会失败，错误框会显示原始输出。
- 重启会中断当前正在执行的任务，包括正在跑的 Agent 回合。
