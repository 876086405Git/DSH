# 客户端模块每轮注册使用首次匹配的包清单

ClientModuleRegistry 为 Loader 条目向上查找 package.json 时，同一次解析使用首次成功匹配的完整清单取得包名、dsh.client 和 ./client。若进程外在这次读取后替换或删除文件，本轮仍按已取得的内容处理。下一次实际触发的 Loader 刷新重新读盘，可以观察当时的内容或缺失。裸包名分支若只解析出文件路径，仍在取得路径后读取清单。

无法解析的祖先清单按既有顺序继续查找；声明校验、导出条件、源码读取和报错各走原路径。运行同名仓例时把 DSH_TEST_PREFIX 或 DSH_PREFIX 指向已准备的完整引擎。它在第一次读取返回时原子替换测试清单，验证两轮注册各自的声明和读取次数。
