# 冷开会话时复用已解码的相同存档

每个读取者独立选择会话文件、查版本并读取自己的物理字节。两个读者都错过读取前的缓存，后到的读者可查已有的两项 LRU。只有同会话、同版本令牌、同规范文件路径，而且原物理 Buffer 的弱引用仍有效、两份字节完全相同，才复用上一次成功验证的完整结果。每个读者仍核对路径与会话身份、检查自己的取消信号，成功后按原顺序更新 LRU。弱引用允许垃圾收集器释放已读文件。

正在迁移的日志、从断尾恢复的结果以及别名路径不建立这个弱引用。原文件在两次读间变化或弱引用已失效时，沿既有流程解压、验证并报告原错误。当前后端的已解码事件及数组由发布方冻结；持久化接口将会话头约定为不可变。
