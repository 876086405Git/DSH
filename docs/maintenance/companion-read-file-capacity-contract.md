# 伙伴任务输入文件的有界缓冲

笔记、草稿、收据与已登记产物共用 companionReadFile。它打开限定目录内的 no-follow 文件描述符，确认文件类型、大小以及要求的版本或身份。符合上限后，以描述符报告的大小加一个字节分配第一次读取的缓冲。稳定文件只保留实际内容的空间以及判断 EOF 所需的一个字节；空文件返回长度为零的视图。

只有实际读取填满这个初始缓冲，且已读字节数仍未超过任务上限时，才扩到上限加一，并拷贝已经读取的字节。这样文件在 stat 后增长时，仍能识别超过任务限额与不超额但版本变化这两种原有错误。增长时会增加一次分配与复制，短时旧、新两块并存。读取字节上限、取消检查、读后描述符和路径版本、SHA-256、BOM/严格 UTF-8 与二进制文本拒绝沿用原有契约。

同名用例通过真实文件描述符读取小收据，检查返回字节与摘要、底层缓冲容量，以及 stat 后增长超过上限的错误。公共覆片位于 companion-find-drafts-files.diff 之后，后续同一文件的公共和 OHOS 覆片应依顺序重录摘要。
