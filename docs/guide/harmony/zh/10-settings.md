# 设置

点对话列表底部的齿轮打开设置，按住齿轮直接搜索；旁边的圆键是「全部功能」，「设置」快捷卡也在那里。网页模式下点 App 标志，选 **App 设置**。

<!-- nav: commonSettings -->
`设置` · [打开](dshgo://open/settings)

设置按要做的事分成六组：AI、能力、外观、通用、主机、帮助与关于。进入子页的每一行右侧显示当前的状态。

## 搜索

点最上方的**搜索设置**，输入名称或常见说法，中英文都可以，例如「深色」「保活」「别问我」「api key」。改过名字的设置用旧名字也能搜到。点结果直接打开那一页，并标出那一行。没有结果时，可以把问题交给 AI，在新对话里回答。

## 顶部卡片

显示 DeepSeek 账号或 API Key 以及余额，点开进入账号页。底部一行是本机引擎的状态，点开进入本机引擎页。没有本机环境、也没登录账号、正在用远程主机时，卡片显示当前主机，点开进入远程主机页。

## AI

- **模型**：见 [模型与渠道](02-models.md)。
- **权限**：新对话默认怎样执行命令、修改文件，见下文「权限」。
- **个性化**：
  - **个人偏好**：写下希望 AI 遵循的要求，新对话会照这里回答。清空后保存即删除。
  - **可视化回复**：默认开启，本机引擎上的 AI 可以用图表、对比卡和可点的选项回答。引擎重启后生效，改完可点**立即重启**。
  - **Agent 预设**：选择新对话默认的工作方式，也可以新建、复制、编辑。预设决定这个对话能用哪些工具。**标准模式**、**PTC 模式**这类编程预设带 `bash`、`run_code` 等命令工具；纯人设的自定义预设可能一个工具都没有，新建对话时注意选对预设。
  - 前两项只在使用本机引擎时显示。

## 能力

- **系统操作**：见 [系统操作](04-phone-control.md)。
- **联网搜索**：当前主机的联网搜索，可以填 API Key，或改用**新版搜索 API**。
- **插件**：见 [插件](08-plugins.md)。部分插件会在下方加上自己的设置项。
- **图像与视频**：当前主机的生成服务、API Key 和默认模型，来自图像与视频插件。添加服务时选服务商即可，填一次 API Key；同一家、同一目标站点的图片和视频可以共用这个 Key，详情会列出共用服务。API 地址填根地址，不要填完整生成接口；编辑时可预览请求地址，换站点或跨站点复用 Key 需要确认。「已保存」不代表鉴权成功；**检查已保存配置**只检查已保存配置，不联网验证 Key、余额或模型权限。主机没有这个插件时，可以**在此主机上安装**。用法见 [对话](01-chat.md)。
- **Linux 环境**：只在鸿蒙版有，在手机里运行 gh、Python 这类命令行工具。开关、代理和用法见 [本机引擎与远程主机](03-engine-hosts.md#linux-环境)。

## 外观

**主题**、**对话字号**、**完成后收起过程**，见 [外观](09-appearance.md)；**宠物**，见 [宠物](06-pets.md)。

## 通用

- **界面**：最上面的**模式**分组可以选**启动时进入**（工作、伙伴或酒馆）；下面选首页用**原生**还是**网页**，以及网页版的选项，见 [网页模式](05-web.md)。
- **语言**：**跟随系统**、**简体中文**或 **English**。
- **通知**：开启**允许通知**后，按需选择**一轮完成**、**出错或被停下**、**等你确认**、**向你提问**。提醒要应用在运行才发得出，系统挂起应用后就没有了；远程主机的提醒还要连接在线。**进度通知**在通知栏显示对话状态，是普通通知，应用被系统挂起后不再更新。声音、横幅和锁屏显示在系统设置里调整，横幅默认关闭。
- **语音**：语音输入的识别方式：**自动**、**DeepSeek**、**系统**或**其他云端服务**。**自动**在登录了 DeepSeek 账号或填了 API Key 时用 DeepSeek，否则用系统识别；用 DeepSeek 或其他云端服务时，录音会发给那个服务。鸿蒙本机引擎没有语音模型，连着远程主机时才能选**语音模型**。这一页还有**朗读的声音**（回复朗读和语音通话都用它）、**实时字幕**（鸿蒙系统识别，显示是否可用，不用下载模型），以及语音通话的**通话背景**、**插话打断**、**停顿多久算说完**、**口语回答**、**默认免提**和**思考提示音**。
- **性能**：**自动**、**完整**或**轻量**，以及玻璃模糊、界面动效、灵动动效、**刷新率**（自动 / 最高 / 系统）和**帧缓存**。
- **后台运行**：离开屏幕后本机的对话会怎样，见 [常见问题](11-faq.md)。
- **系统权限**：各项功能用到的系统权限。[打开](dshgo://open/system-permissions)
- **隐私与分享**：
  - **我的分享链接**：见 [分享与回放](07-sharing.md)。
  - **分享配置**：勾选当前主机上要分享的设置、插件、技能和个人偏好，点**下一步**，以链接、二维码或文件分享。
  - **发送匿名使用统计**：鸿蒙版暂不发送使用统计，这个开关关着，不能打开。
  - **向 DeepSeek 上传对话日志**：当前主机提供这一项时显示。

## 主机

- **本机引擎**、**远程主机**：见 [本机引擎与远程主机](03-engine-hosts.md)。
- **引擎参数**：当前主机的引擎参数。**运行**里有**子代理**、**Agent 循环**、**命令执行**；**插件**里有**插件清单**和插件自己的设置。[打开](dshgo://open/engine-settings)

## 帮助与关于

- **使用帮助**：把「这个 App 能做什么」带进新对话，由 AI 按使用说明回答。网页模式下不显示。
- **社区**：交流群和论坛。
- **诊断**：查看环境、导出诊断包，或**让 AI 看诊断**，也可以开启默认关闭的**自动故障分析**；输入框被键盘挡住时，**本应用键盘几何**可以导出最近两分钟键盘弹出的位置，不含输入内容。见 [常见问题](11-faq.md)。
- **关于 DSH Go**：
  - **版本**：当前 App 版本，例如 0.9.2 (10251234)，括号里是构建号。有新版本时，首页这一行显示**有新版本**。
  - **检查更新**：鸿蒙版不能在应用内更新。有新版本时打开更新窗口，查看**更新内容**，到发布页看获取方式。发布页可能还没有鸿蒙安装包。不想看这一版可以点**跳过这个版本**。
  - **自动检查更新**：默认开启，打开 App 时检查，每天最多一次。发现新版本时弹出更新窗口；你正在别的页面或正在输入时不打扰，只在**检查更新**一行标出。跳过的版本不再提示，也不会下载或安装任何东西。
  - **给 DSH Go 点个 star**：打开项目主页，点个 star 或分享给朋友。
  - **开源许可**。

## 权限

<!-- nav: commonSettings,featuresPermissions -->
`设置 › 权限` · [打开](dshgo://open/permission)

- **当前对话**：打开着对话时出现，只改这个对话。
- **新对话默认**：**仅可查看**、**工作区内修改**或**完全权限**。选**完全权限**前要确认**开启完全权限？**。在本机引擎上它就是原来的「自动执行命令」：原生界面新建的本机对话和自动化任务里，AI 执行命令、改动文件前不再问你；远程主机、网页模式、安全模式和已有的对话不受影响。改回其他档位后，开着时新建的对话仍保持完全权限，可在那个对话的权限里改回。
- 系统操作也按这里的权限询问：完全权限时不问，其他情况每次先问你。见 [系统操作](04-phone-control.md)。
